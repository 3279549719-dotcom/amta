# 副文本版面实验实施计划

**目标：** 在 exp/vlm-direct-ocr 分支，为用户指定样本生成可逐页验收的译文、干净图和成品，不引入作品/页码/固定坐标分支。

**授权与范围：** 用户已授权实现、视觉检查和反复修正。实验留在分支和独立 workspace，普通管线默认行为不变。翻译数组契约修复独立于实验。

**设计：** 本地 detect 提供当前原图的区域；VLM 对区域转写并观察方向、对齐、字形、行数和段落结构；确定性本地擦字、排版执行这些观察。语义方向不由框宽高猜测，感叹号不决定粗体。所有源图和外部模型输出保留来源哈希，实验产物可复查。

**取舍：** 仅强制横排无法处理混排或修复坐标错位；让图像生成模型重绘整页难以保证原画与文字精度。因此采用模型理解版面、现有本地工具执行的路径。优先验证正确框下现有擦字，再对实测残留做通用修正。

## 实施

- [ ] 建立独立实验工作区，对当前源图重新 detect，保留旧缓存。
- [ ] 新增 scripts/probes/paratext_layout.py：VLM 请求、严格解析和源图对应检查；tests/test_paratext_experiment.py 验证越界、缺区域、非法方向均拒绝。
- [ ] 新增 scripts/probes/paratext_render.py：按显式方向排版，按源行数估算字号，保留段落换行；测试竖长框横排、邮箱不拆、像素不越界、标题尺度。
- [ ] 新增 scripts/probes/probe_paratext.py：在进程内替换实验工位，调用 scripts/run_pipeline.py 的 main；复用编排、翻译、报告，不接入正式默认注册表。
- [ ] 原图 → detect → VLM canon/版面 → translate → 本地 inpaint → typeset；用源行和显式字体样式保持版面层级，输出完整检查数据。
- [ ] 先跑月天 1 和单翼 40，检查原图/clean/final，修复实际失败后扩至所有样本。
- [ ] 样本：月天 1、38、39、55、63、67；单翼 1、5、40。单翼 1 是混排能力的竖排对照。
- [ ] 生成现有 report 深接口的逐页对照 HTML，逐页看图并检查转写/译文完整性。失败页继续迭代，未验证不得标记通过。
- [ ] 补翻译数组回归测试，验证后独立提交；实验通过项目检查后另行提交在实验分支。

## 验收

每页原图尺寸一致，所有区域与源图对应；译文完整且无乱码；无可见原文残留或原画损坏；方向符合源文，字号可读，无文字裁切/重叠。自动检查只证明其覆盖的不变量，视觉质量以原图/clean/final 实际检查为准。
