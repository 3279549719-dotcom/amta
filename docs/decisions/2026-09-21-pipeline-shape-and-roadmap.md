# 2026-09-21 管线现状与下一步方向（口述整理）

> 来源：一次语音口述现场整理。事实型细节（模型具体版本、阈值数值）以 config 为准，
> 本文只记"为什么这么选"和"接下来想往哪走"，不抄会过期的数字。

## 各站选型（当前状态）

- **Detect**：RT 系检测器，confidence 调到 0.5。
  为什么不是 0.7？为了多检出框外小字——0.7 会把贴边的小气泡滤掉。（型号见 config，不写死在此。）
- **OCR**：hayai，confidence 0.7。
- **Translate**：DeepSeek flash（纯 LM 调用），前置术语库加载替换（见 ADR 031）。
- **Inpaint**：LaMa 本地推理（见 ADR 029）；均匀背景直接填色、复杂背景走 LaMa（见 HANDOFF）。
- **Typeset**：自研 Pillow 引擎（见 ADR 021），横竖排并存，目标美观 + 字体最大化。

## 一个待验证观察（还没做决定）

DeepSeek flash 这一代模型本身已带视觉能力，未来 translate 可能不再需要
"纯 LM" 和 "独立 VLM" 两条路分开。**留待后续实践验证，现在不改。**

## 产品方向 backlog

### 1. 长文本页的 VLM 专用读取 + 开关 + GUI

大量文字的首尾页 / 长对白页，普通 detect+OCR 路线读不动，要引入专用视觉模型读文本。
要做开关（哪些页走 VLM、哪些走普通路线）→ 开关需要一个 GUI 界面。

### 2. 产物分流：原图进，成品图 + PSD 出

现在一张原图进，detect/ocr/translate/clean/最终图一堆中间产物全落盘。
目标收敛成：原图 → 成品图 + 一个 PSD。
PSD 计划图层：嵌字文字层 + 干净底图层（供人工修）。

**未决**：如果 inpaint 阶段就把原图搞坏了怎么办？PSD 里"干净层"该长什么样、
图层怎么分，还没想清楚，先记着。

### 3. 全部转缓存，中间产物不落盘

中间结果放 RAM / artifacts cache，不再每个都写硬盘。
和第 2 条是同一件事的两面：不堆中间文件，只在出口产出成品。
