# ADR-035: p62 背景保护闭环停止于能力边界

- 日期：2026-09-25
- 状态：实验结束，生产代码不变
- 开发样本：`月天新地` p62
- 隐藏验证：p26、p60（未运行候选方案）

## 问题是否真实

p62 的问题发生在 typeset 之前。当前 `inpaint_station._build_mask_image` 把
`r00=[1146,1850,1546,2346]` 整个矩形交给 LaMa，clean 图因此重绘了约
400×496 的人物、黑色背景和网点。原日文虽被清除，但结果不是指标假象：原画结构已经明显丢失。

当前基线来自已有 pipeline log：p62 inpaint 用时 50.88 秒，7 个区域，
`pixel_diff_ratio=0.1534`。这个比例只能证明发生过修改，不能证明修改正确。

## 复用的项目能力

- 当前 RT-DETR bbox、translation 过滤契约、lama-manga 与 artifact。
- `models/CTD/comictextdetector.pt.onnx` 的 DBNet 行概率图。
- ADR-029 的全页/局部推理经验、ADR-033 的矩形 mask 决策边界。
- `fix/text-ink-mask` 的中值滤波差分实验。该方法会同时响应网点和线稿，未直接合并。
- 历史 CTD 探针推荐值：阈值 0.1、9×9 椭圆核膨胀 7 次。

## 三轮实验

### 1. CTD 像素 mask + 全页 LaMa

假设：CTD 能把大矩形缩成文字实例 mask，从而保留框内原画。

结果：CTD 推理 14.50 秒；初始 mask 覆盖 r00 的 41.41%。CTD 能定位黑色字芯，
但没有覆盖粗白描边。较小膨胀保住人物，却留下完整白色“幽灵字”；使用历史推荐的
7 次膨胀后日文消失，但各列文字连接成大片 mask，LaMa 仍把人物补成模糊黑白块。
全页 LaMa 实测 60.61–81.28 秒，加上 CTD 后慢于 50.88 秒基线。

结论：否定。继续调膨胀量只会在残字和多擦原画之间移动。

### 2. 带上下文 crop 推理，只合成 mask 内像素

假设：ADR-029 的 crop 白框来自整块贴回；局部高分辨率推理并仅合成 mask 内像素，
可以恢复人物线条。

结果：620×814 crop 的 LaMa 推理降至 22.97 秒；连同 CTD 总计约 37.47 秒，
速度优于基线。日文被清除，但人物仍被补成无结构的渐变块。局部分辨率改善了耗时，
没有改善被遮挡内容的重建能力。

结论：否定。瓶颈不是输入分辨率。

### 3. CTD 字芯引导的高亮描边生长

假设：从 CTD 黑色字芯有限距离内只吸收高亮像素，可以覆盖白描边并在人物线条处停止。

结果：mask 在运行 LaMa 前即失败。白描边与人物白色脸部/衣服在颜色和空间上连通，
引导 mask 覆盖 r00 的 44.98%，并吞掉人物区域。调整亮度或距离阈值将成为 p62 专用规则。

结论：否定，未运行第三次 LaMa。

## 决策

不修改 detection、inpaint、typeset 接口，也不把三种实验实现或页面规则加入生产代码。
p62 没有通过开发页验收，因此按预注册流程不运行 p26、p60；隐藏页仍保持隐藏验证用途。
本轮也不添加声称修复成功的回归测试。

## 能力盲区与下一步进入条件

现有系统缺少两种能力中的至少一种：

1. 能把黑色字芯、粗白描边与相邻人物白色区域分开的实例级文字 mask；
2. 能根据角色上下文重建被大号文字真实遮挡的线稿/网点的漫画修复模型。

下一轮只有在引入一个可离线运行、具有上述能力的候选模型后才值得启动。候选模型必须先在
p62 生成可视 mask 或 clean，证明日文清除且人物结构明显优于基线；随后才能首次运行 p26、p60。
在此之前继续组合阈值、形态学核或页面类别会造成样本过拟合。

## Loop Engineering 结论

现有项目已经能够完成“读取历史证据 → 提出假设 → 运行本地模型 → 视觉否证 → 停止”的闭环。
本轮没有成功修复，但成功阻止了一个只在 p62 上调参、随后宣称通用的改动进入主线。
当前主要缺口是模型能力与可量化的实例 mask 真值，而不是再增加外层 Agent 编排。
