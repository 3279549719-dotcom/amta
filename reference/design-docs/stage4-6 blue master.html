Hardware & Execution Profile

02 算力适配：针对 i5-1135G7 / Iris Xe 的轻量化工程

本项目彻底抛弃体积庞大、依赖地狱的 PyTorch CUDA 环境，所有本地 CV 视觉模型全部固化为 .onnx 格式，利用 onnxruntime 驱动 Intel Tiger Lake 的 AVX-512 指令集，单页 CPU 端计算总耗时仅约 3~5 秒，内存占用 < 1.8 GB。

工位阶段 选用模型 / 引擎 模型大小 运行环境 i5-1135G7 CPU 耗时
1. Text Detect Comic-Text-Detector (CTD) / DBNet ~20 MB 本地 onnxruntime ~0.25 s / 页
2. Text OCR Manga-OCR (ViT+Seq2Seq) ~150 MB 本地 onnxruntime ~0.4 s / 文本框
3. Translate DeepSeek-V3 / Qwen2.5-72B 云端 API HTTPS Rest API ~1.5 s / 页
3b. SFX Arbiter Qwen2.5-VL-7B / GPT-4o-mini (Vision) 云端 API 按需 Tool Call ~1.0 s (仅20%边缘触发)
4. Text Mask Manga-Text-Segmentation (U-Net) ~30 MB 本地 onnxruntime ~0.3 s / 区域
4b. Inpaint Anime-LaMa (FFC ResNet) ~190 MB 本地 onnxruntime ~0.8 s / 局部裁剪块
5. Typeset Pillow 自适应数学排版引擎 0 (纯算法) 本地 Python 纯脚本 < 0.02 s / 页
6. QA Gate 几何与多边形内切求交校验 0 (纯算法) 本地 Python 纯脚本 < 0.005 s / 页
Pipeline Stages

03 六大工位核心技术与决策实现

Stage 1: Detection & SFX Triage (检测与拟音词分流)

  • 三级分类：dialogue_bubble（框内对白）、overlay_text（图上/压脸文字）、sfx（拟音词）。
  • SFX 保护策略：
    • 快速初筛：面积极小且周围留白（如 プチッ）$\rightarrow$ 标记 safe，执行擦除重嵌；占全图 > 15% 且极度扭曲 $\rightarrow$ 标记 skip 保全画风。
    • Vision Tool 仲裁：灰色模糊地带（如穿过发丝的 ビクッ），向视觉模型发送 Crop 图裁决 safe_to_inpaint 或 side_annotation（旁注）。

Stage 2: OCR & Canonical Arbitration (光学识别与文本规范化)

  • 使用针对日漫竖排调优的 Manga-OCR 提取文字候选。
  • 去除假名注音（Furigana）干扰，校正标点，输出规范化 source_text。

Stage 3: Translation Harness (受控翻译与状态机)

  • 由 DeepSeek 作为 Translator，结合东方 Project 专有名词表（Glossary）与作品状态（Story State）。
  • Guardrails 门禁：输出强制包含 region_id、target_text、style_category，字数必须精炼。

Stage 4: Mask & Inpainting (图像去字与底图修复)

  • 纯色气泡旁路（Bypass Invariant）：白底气泡直接连通域填充纯白（#FFFFFF），0 毫秒开销，彻底消除糊斑。
  • 图上文字像素级修复：对压脸字执行 U-Net 笔画提取 + $\max(2, \lfloor stroke \times 0.5 \rfloor)$ 像素自适应膨胀；裁剪小 Patch 丢给 Anime-LaMa ONNX 修复并贴回。
  • 色彩守恒（Grayscale Invariant）：贴回后强制色彩空间对齐，杜绝黑白漫产生彩色噪点。

Stage 5: Typesetting Engine (自适应椭圆嵌字排版)

  • 方向决策：中文默认首选横排居中；仅在长宽比 $H/W \ge 2.2$ 且字数 $\le 6$ 时切换为竖排。
  • 椭圆内切与避头尾折行：根据气泡内切安全区进行动态断行；禁止逗号、句号、感叹号顶格出现在行首。
  • 二分字号查找：在 $[12\text{px}, 52\text{px}]$ 区间搜索最佳容纳字号。
  • 4 类字体映射与描边：
    • 普通对白 $\rightarrow$ 动漫黑体 / 方正准圆（无描边）
    • 图上/独白 $\rightarrow$ 楷体（强制加 2.5px 白色描边）
    • 呼喊/感叹 $\rightarrow$ 粗魏碑 / 力量黑
    • 可修 SFX $\rightarrow$ 手写漫画体

Stage 6: Programmatic QA & Repair Loop (自动化质检与反压闭环)

  • 100% 覆盖率检查：校验 len(Rendered) == len(Detected)，杜绝漏字。
  • 反压自愈回路：若排版字号触底（$< 12\text{px}$），计算最大安全字数（如 8 字），向 Translation Harness 抛出单句重写请求（Retry Budget = 2 次），无需整页重跑。

05 关键排版、去字算法与自愈硬约束

自适应椭圆折行与字号二分查找

def fit_text_to_bubble(text, bbox, min_sz=12, max_sz=48):
    w = bbox[2] - bbox[0]
    h = bbox[3] - bbox[1]
    safe_w = w * 0.85  # 内切安全宽
    safe_h = h * 0.85  # 内切安全高
    
    best_font_size = None
    best_lines = []
    
    low, high = min_sz, max_sz
    while low <= high:
        mid = (low + high) // 2
        lines = wrap_with_kinsoku(text, mid, safe_w)
        total_h = len(lines) * (mid * 1.2)
        
        # 校验菱形/椭圆边界与高度
        if total_h <= safe_h and all(get_width(l, mid) <= safe_w for l in lines):
            best_font_size = mid
            best_lines = lines
            low = mid + 1  # 尝试更大字号
        else:
            high = mid - 1
            
    return best_font_size, best_lines

反压重修闭环 (Backpressure Loop)

def handle_qa_overflow(region_id, text, max_capacity, retry_budget=2):
    for attempt in range(retry_budget):
        repair_prompt = f"""
        【排版溢出告警】
        原文: {text}
        当前字数超出气泡安全区。
        硬约束: 请将译文精炼缩短至 {max_capacity} 个汉字以内，保持语气。
        """
        condensed_text = call_deepseek(repair_prompt)
        font_sz, lines = fit_text(condensed_text)
        if font_sz >= 12:
            return condensed_text, "REPAIRED"
            
    return text, "FLAGGED_FOR_MANUAL_REVIEW"
