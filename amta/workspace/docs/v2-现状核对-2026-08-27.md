## 3. ADR-022 核心结论（Task 0 已完成，勿回退）

- 严格命中率 12/15 = 80%（达完整闭环阈值线）
- 误读/漏检检测强；**幻觉检测有假阳性风险**（2/5 页把真实小字判成幻觉）→ 不自动删
- vision-exp 是推理模型：复杂任务 max_tokens 全耗 reasoning_content，content 恒空（finish=length）→ **分块 ≤6 条/次 + max_tokens 8000**；"不要推理"指令无效
- **两趟式 audit 定稿**（替代计划 Task 6-9 的单趟设计）：
  - Pass1 存在性确认（hallucination/misread）：crop 多图批量 → VLM 转写/判空 → 机械判定；**终参数批量 3 图**（6 图在密页 50% 螺旋）
  - Pass2 漏检枚举（missed）：整页图 + 无清单枚举 prompt → 机械 diff → 方位框 re-OCR 确认
  - 计时：简页 49s / 密页 129s；41 页预估 1.5-2.5h
- 安全阀：hallucination 需 For-Manga 重 OCR 为空 + 墨量<1% 双条件才自动删；misread 编辑距离 ≤2 降级；missed 不自动合入；region_id 后缀归一；方位词中英文兼容
