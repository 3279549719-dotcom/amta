Root Cause Diagnosis

01 案发现场与“展平吞噬”根因剖析

结论先行：在 15.jpg（「弟子だからね」）和 14.jpg（「では豊ちゃん…」）的漏检并不是上游模型没有识别出气泡，而是 geometry.py 在执行 build_regions 和 flatten_regions 时，发生了“容器吸收单子行后自身被灭口”的逻辑结构性吞噬。

案发现场还原 (15.jpg 左下气泡)

【气泡物理区域: [50, 2395, 210, 2698] (宽约 160px)】
  ├── 右侧大字 (主台词): 「弟子だからね」 (宽约 100px)
  └── 左侧小字 (碎碎念): 「落ち着きなさい」 (宽约 52px)

【流水线内部执行时序追踪】
1. comic-text-bubble-detector 成功检出大气泡容器:
   Container = [50, 2395, 210, 2698] (width = 160px)
2. anime-text / CTD 仅检出高密度小字行:
   ChildLine = [145, 2395, 197, 2698] (width = 52px)
3. build_regions 判定嵌套 (IoA >= 0.75):
   ChildLine 被挂载到 Container.child_lines = [ChildLine]
4. flatten_regions 执行展平 (致命 Bug 点):
   规则: "容器自身不输出，只输出 child_lines"
   ==> Container (160px) 被丢弃！
   ==> 仅输出 ChildLine (52px「落ち着きなさい」)！
   ==> 大字「弟子だからね」在没有被独立检出的情况下，其依托的母体容器被流水线自己杀死了！
Algorithmic Solution

02 核心算法：残差保底律 (Residual Container Fallback)

不要试图在 Stage 1 强行切碎气泡。Manga-OCR（ViT 架构）具有极强的多行整气泡自回归识别能力。当子行未能覆盖整个气泡时，母体容器必须作为保底实体被保留并传递给下游。

覆盖率数学判定（Coverage Ratio）

对于任意气泡容器 $C$ 及其吸收的所有子行集合 $\{L_1, L_2, \dots, L_k\}$：

$$\text{Coverage}(C) = \frac{\text{Area}(\bigcup_{i=1}^k L_i)}{\text{Area}(C)}$$
覆盖率阈值 物理状态判定 `flatten_regions` 展平处理动作
$\text{Coverage} \ge 0.60$ 且 $k \ge 2$ 完全分解成功
(大字与小字行均被各自检出)		 按原有逻辑正常展平，输出各个 child_lines 进行分段排版。
$\text{Coverage} < 0.60$ 或 $k == 1$ (且 $W_C > 1.5 W_L$) 严重残差漏检
(气泡内存在大片未被子行覆盖的有效区域，如仅检出 52px 小条)		 【触发残差保底】禁止丢弃容器！
丢弃细碎单子行，直接将母体气泡容器 $C$ 整体输出，送给 02_ocr 进行完整上下文识别。

03 目标文件与代码重构清单

修改文件 1: `src/amta/geometry.py`

重构 flatten_regions 与 build_regions 函数，增加覆盖率判定逻辑：

# src/amta/geometry.py

def calculate_box_area(box: List[int]) -> int:
    return max(0, box[2] - box[0]) * max(0, box[3] - box[1])

def flatten_regions(regions: List[Dict[str, Any]], min_coverage_ratio: float = 0.60) -> List[Dict[str, Any]]:
    """
    将层级 regions 展平为供 02_ocr 裁框的扁平列表。
    【核心修复】: 若容器内 child_lines 覆盖率不足 60%，说明存在内部大字漏检，
    此时回退 (Fallback) 保留母体容器框，绝不丢弃母体。
    """
    flattened = []
    
    for reg in regions:
        child_lines = reg.get("child_lines", [])
        
        # 1. 孤立区域 (无子行)，直接输出
        if not child_lines:
            flattened.append(reg)
            continue
            
        # 2. 计算子行总面积对容器的覆盖率
        container_area = calculate_box_area(reg["bbox"])
        if container_area == 0:
            continue
            
        child_total_area = sum(calculate_box_area(c["bbox"]) for c in child_lines)
        coverage_ratio = child_total_area / container_area
        
        # 3. 覆盖率检查与残差保底决策
        # 如果只有 1 根极窄子行，但容器很宽 (如 160px 容器只包了 52px 小字)
        is_severely_undercovered = (coverage_ratio < min_coverage_ratio) or (
            len(child_lines) == 1 and (reg["bbox"][2] - reg["bbox"][0]) > (child_lines[0]["bbox"][2] - child_lines[0]["bbox"][0]) * 1.5
        )
        
        if is_severely_undercovered:
            # 触发保底：丢弃不完全的子行，直接输出完整大气泡容器！
            fallback_region = dict(reg)
            fallback_region["child_lines"] = [] # 清空单子行，作为完整气泡送 OCR
            fallback_region["fallback_triggered"] = True
            flattened.append(fallback_region)
        else:
            # 正常多行完整覆盖，展平输出各子行
            for child in child_lines:
                flattened.append(child)
                
    return flattened

from amta.geometry import flatten_regions

def test_single_narrow_child_line_triggers_container_fallback():
    # 模拟 15.jpg 案发现场
    mock_container = {
        "region_id": "c_001",
        "bbox": [50, 2395, 210, 2698], # 宽 160px 的大气泡

            {
                "region_id": "l_001",
                "bbox": [145, 2395, 197, 2698], # 宽 52px 的小字「落ち着きなさい」
                "category": "dialogue_bubble"

        ]
