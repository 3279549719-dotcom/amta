Architectural Epiphany & Global Reconstruction

AMTA 数字工厂全景架构蓝图 (无限画布版)

从过度微观的“分字号规则枷锁”中解脱，转向“粗粒度高召回采集（Stage 1）+ 多引擎会诊过滤（Stage 2）+ 语义级完整理解（Stage 3）+ 自适应包络排版（Stage 5）”的现代 AI Harness 范式。

Core Principle 1

The Bitter Lesson

苦涩的教训（Rich Sutton）：AI 历史上最大的教训是，任何试图将人类微观经验（如硬编码行宽比 1.4、硬切气泡大小字）写进前处理的算法，最终都会被通用大模型和粗粒度计算彻底击垮。

“粗粒度全量捕获 + 语义模型自然理解，永远胜过死板的启发式切分。”
Core Principle 2

Anthropic Harness Design

持续删除 Harness 假设：Anthropic 强调必须持续删除随着下游模型能力增强而变得多余的中间态。不要逼迫无语义的 CV 检测器去分辨主台词和碎碎念，那本就是 LLM 的本职工作。

“Avoid over-constraining the pipeline with brittle micro-processors.”
Core Principle 3

OpenAI Invariant Engineering

守住不变量，而非微观指令：OpenAI Harness 理论指出，系统应当定义清晰的边界不变量（Stage 1 绝不漏字，Stage 2 绝不过噪，Stage 5 绝不溢出），并在工件边界留出足够的自愈反馈回路。

“Guard boundary invariants, do not micromanage intermediate steps.”
STAGE 01

粗粒度高召回采集 (Coarse Ingestion)

不变量: 召回率 ≥ 0.99，宁滥无缺，绝不微观切碎

彻底废除脆弱的 sub_tier 与单行强制剥离逻辑。 Stage 1 退回其本质角色 —— “大功率采砂机”。

  • 4 检测器并集 (2048px + conf=0.25)：确保包括 かっこいい 在内的所有微小字符被 100% 圈出。
  • 气泡容器整吞 (Container Preservation)：对于气泡（Bubble），直接输出整颗完整气泡框（如 160px 宽框），绝不因为只扫到 52px 小条而把母体丢弃！
  • 无框多行空间聚类：仅对裸露在外的背景独白按日漫从右向左拼接为单一多行段落。

STAGE 02

多专家会诊与看门狗除噪 (Consensus & Sieve)

不变量: 100% 阻断排线假框，输出纯净日文字符串

给下游洗净泥沙，将 0.25 宽门槛带来的排线噪点物理抹杀。

  • Baberu-OCR 整气泡识别：直接对整颗气泡大框做 OCR，Manga-OCR 会自然按日文语法读出完整自然句：弟子だからね 落ち着きなさい。
  • Pass 1 批量 VLM 差异提示 (ADR-022)：3 图/批，关闭推理思考，2.5s 秒级完成存在性校验。
  • 幽灵排线过滤筛 (Phantom Sieve)：若 Baberu 读出乱码（エーマン）且 VLM 陷入条纹幻觉（こ、こ、こ...），且两者重合度为 0，直接 DROP 该区域。

STAGE 03

语义级受控翻译 (Translation Harness)

不变量: 语义完整，专有名词锁定，自然保留语调层级

让 DeepSeek 在完整的语言上下文中进行人类级的语气分层。

  • 天然语调理解：DeepSeek 拿到 弟子だからね 落ち着きなさい，天然理解前半句是正式答复，后半句是安抚叮嘱。

STAGE 04

无损图像去字 (Clean Image Inpainting)

不变量: 灰度守恒，白底 0 耗时，线稿网点无损

机械化底图处理，不引入多余模型。

  • 气泡连通域纯白直填 (Bypass)：整颗气泡内壁直接 `#FFFFFF` 覆盖，0 毫秒开销，绝不糊网点。
  • 压脸文字 U-Net 分割 + LaMa 局部修复：仅对无框字执行细粒度笔画膨胀与 Patch 局部贴回。

STAGE 05

智能自适应排版 (Adaptive Typography)

不变量: 绝不戳破气泡边界，括号小字自动降级

把所谓的“大小字分级”彻底下放到排版引擎中用纯数学解决！

  • 括号/副句自适应缩放：排版引擎检测到译文中包含换行或括号 (...) 时，自动对括号内文本应用 0.7x 字号渲染！
  • 椭圆内切安全区二分折行：在气泡包络内二分搜索主字号，让整段文字完美贴合椭圆气泡。
  • 避头尾规则：禁止标点顶格掉落行首。
