Step 4 (Verification)

Step 4 验收门禁与断言 (Acceptance Criteria)

在代码实现完成后，使用以下 4 条硬性断言（Assertions）进行单元测试与流水线验证：

Gate 1: 召回率底线

Recall ≥ 0.98

在 1~10 页基准测试集上，目标文本检出数必须恢复至 ≥ 99 / 101。单页检出框数必须恢复至 8~15 个，严禁回退至 3~4 个。

Gate 2: 零重复切片

Zero Fragment Duplicates

断言：气泡外部大框与其内部包含的单行，严禁在 regions 顶层同时存在。大框必须完整吸收小条。

Gate 3: 极小字感知

Tiny Text Captured

断言：样本页第 3 格帽子旁的 かっこいい（面积 < 3000px²，手写体）必须被成功生成独立检测框。

Gate 4: OCR 伪检自净

OCR Self-Pruning

断言：因放宽检测门限产生的网点虚警，经 Manga-OCR 识别后若为空字符串或连续乱码，必须在进入 Stage 3 前被静默剔除。

Step 3 (Assembly)

Step 3 语义组装：竖排多行空间聚类算法

为了让没有气泡包裹的长篇独白（如左上角压脸字）不被切成 3 句孤立台词，必须对孤立文字行执行**日漫空间聚类**：

聚类数学约束与算法逻辑

给定两个孤立竖排文本框 Box_A (x1, y1, x2, y2) 与 Box_B (x3, y3, x4, y4)：
1. 竖排判定: (y2 - y1) > (x2 - x1) 且 (y4 - y3) > (x4 - x3)
2. 水平间距: Δx = min(|x1 - x4|, |x3 - x2|) ≤ max(width_A, width_B) * 1.2
3. 垂直投影重叠率: Overlap_Y = max(0, min(y2, y4) - max(y1, y3)) / min(h_A, h_B) ≥ 0.50
4. 满足以上条件则合并为同一段落，且严格按 x_center 从大到小 (从右到左) 排序。
Step 2 (Fusion)

Step 2 结构融合：分层包含度挂靠 (IoA Fusion)

彻底解决“气泡检测器输出大块、文字检测器输出细长条”导致传统 NMS 彻底失效的问题：

包含度 (IoA) 计算公式与归并决策

$$\text{IoA}(\text{Line}, \text{Container}) = \frac{\text{Area}(\text{Line} \cap \text{Container})}{\text{Area}(\text{Line})}$$
条件分支 判定结果 动作 (Action)
$\text{IoA} \ge 0.75$ 文字行完全落在气泡内部 气泡吞掉该文字行：将文字行挂载为气泡的 child_lines，不产生顶层独立框。
$\text{IoA} < 0.75$ 且无相交容器 孤立文字行 (图上字 / SFX) 保留为独立孤立行：送入 Step 3 参与空间邻近聚类。
两个容器重叠 ($\text{IoU} \ge 0.6$) 同属气泡检测器的冗余框 标准 NMS 保留置信度更高的单一气泡容器。

07 生产级 Python 模块实现（可直接给本地 AI 落地）

以下是经过逆向推导完整闭环的 stage1_detect.py 核心代码实现：

# pipeline/stage1_detect.py
import json
import cv2
import numpy as np
from typing import List, Dict, Any

def calculate_ioa(box_child: List[int], box_parent: List[int]) -> float:
    """计算子框与父框的面积包含率 Intersection-over-Area(Child)"""
    x1 = max(box_child[0], box_parent[0])
    y1 = max(box_child[1], box_parent[1])
    x2 = min(box_child[2], box_parent[2])
    y2 = min(box_child[3], box_parent[3])
    
    inter_w = max(0, x2 - x1)
    inter_h = max(0, y2 - y1)
    inter_area = inter_w * inter_h
    
    child_area = (box_child[2] - box_child[0]) * (box_child[3] - box_child[1])
    if child_area == 0:
        return 0.0
    return inter_area / child_area

def cluster_vertical_orphan_lines(orphan_lines: List[Dict[str, Any]], max_dx_ratio=1.2, min_y_overlap=0.5) -> List[Dict[str, Any]]:
    """对无气泡包裹的竖排文字行进行空间邻近聚类 (日漫从右向左序)"""
    if not orphan_lines:
        return []
    
    # 按照 X 坐标降序排序 (日漫从右向左读)
    sorted_lines = sorted(orphan_lines, key=lambda b: (b['bbox'][0] + b['bbox'][2]) / 2, reverse=True)
    clusters = []
    
    for line in sorted_lines:
        bx1, by1, bx2, by2 = line['bbox']
        bw = bx2 - bx1
        bh = by2 - by1
        
        matched_cluster = None
        for cluster in clusters:
            cx1, cy1, cx2, cy2 = cluster['bbox']
            # 计算水平间距
            dx = abs(bx1 - cx2) if bx1 > cx2 else abs(cx1 - bx2)
            # 计算垂直重叠
            y_overlap = max(0, min(by2, cy2) - max(by1, cy1)) / max(1, min(bh, cy2 - cy1))
            
            if dx <= bw * max_dx_ratio and y_overlap >= min_y_overlap:
                matched_cluster = cluster
                break
        
        if matched_cluster:
            # 扩展集群 BBox
            matched_cluster['bbox'] = [
                min(matched_cluster['bbox'][0], bx1),
                min(matched_cluster['bbox'][1], by1),
                max(matched_cluster['bbox'][2], bx2),
                max(matched_cluster['bbox'][3], by2)
            ]
            matched_cluster['child_lines'].append(line)
        else:
            clusters.append({
                'category': 'overlay_text',
                'bbox': [bx1, by1, bx2, by2],
                'reading_direction': 'vertical',
                'child_lines': [line]
            })
            
    return clusters

def hierarchical_fusion(containers: List[Dict], text_lines: List[Dict], ioa_thresh=0.75) -> List[Dict]:
    """分层包含度融合主入口"""
    final_regions = []
    unabsorbed_lines = []
    
    # 1. 遍历所有文本行，尝试挂靠到气泡容器
    for line in text_lines:
        absorbed = False
        for container in containers:
            if calculate_ioa(line['bbox'], container['bbox']) >= ioa_thresh:
                if 'child_lines' not in container:
                    container['child_lines'] = []
                container['child_lines'].append(line)
                absorbed = True
                break
        if not absorbed:
            unabsorbed_lines.append(line)
            
    # 2. 已吸收子行的气泡直接作为 dialogue_bubble 区域
    for container in containers:
        if container.get('child_lines'):
            # 内部行按从右向左排序
            container['child_lines'].sort(key=lambda b: (b['bbox'][0] + b['bbox'][2]) / 2, reverse=True)
            container['category'] = 'dialogue_bubble'
            container['reading_direction'] = 'vertical'
            final_regions.append(container)
            
    # 3. 未被吸收的孤立行进行日漫空间聚类
    clustered_overlays = cluster_vertical_orphan_lines(unabsorbed_lines)
    final_regions.extend(clustered_overlays)
    
    return final_regions

def run_stage1_detect(page_id: str, image_path: str) -> Dict[str, Any]:
    """Stage 1 调度函数"""
    img = cv2.imread(image_path)
    h, w = img.shape[:2]
    
    # Step 1: 以 2048px 高分与 0.25 宽门限运行 4 个 ONNX 检测器
    # raw_containers = run_bubble_detectors(img, conf=0.35, size=1600)
    # raw_lines = run_text_detectors(img, conf=0.25, size=2048)  # 能精准捞出「かっこいい」
    
    # Step 2: 分层融合与空间聚类
    # final_regions = hierarchical_fusion(raw_containers, raw_lines, ioa_thresh=0.75)
    
    # Step 3: 输出规范 DetectionArtifact
    artifact = {
        "page_id": page_id,
        "image_meta": {"width": w, "height": h},
        "regions": [] # final_regions 带上 region_id 编号
    }
    return artifact
